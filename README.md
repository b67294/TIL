# TIL · 今天学到的东西

记录具体的发现、理解和踩坑，方便以后找到和复用。不要求每天写，也不要求写成教程。

## 怎么写

- 一篇只写一个发现，文件名直接说明问题。
- 正文写清：发现了什么、什么情况下成立；需要时附代码、图片或来源。
- 区分亲自验证、阅读所得和待验证的猜测。
- 图片放在 `assets/`，使用相对路径引用，避免依赖临时鉴权链接。

直接在当前 Obsidian 库中编辑即可，无需切换库。这个文件夹使用独立 Git 仓库管理；目前没有连接远程仓库。

## 公开之前

逐篇检查公司内部信息、凭证、截图和素材授权。私人摘录与未脱敏实验材料不要放进准备公开的提交中。

Git 可能保留历史内容：敏感信息即使从当前文件删除，也不代表已经从历史中移除。
