熟悉一下Python中几种常见的用于编写http请求的写法。
主要涉及 `urllib`/`requests`/`httpx`/`aiohttp`

### 1.Python自带标准库：`urllib`
```python
from urllib.request import Request, urlopen
import json

url = "https://httpbin.org/anything"

# --- 1. GET 请求 ---
# urllib 默认无 data 就是 GET
get_req = Request(url)
with urlopen(get_req) as response:
    print("urllib GET 结果:", response.read().decode("utf-8"))


# --- 2. POST 请求 ---
# 必须手动转 JSON 并编码成 bytes，有 data 时自动变为 POST
body = {"name": "ZhangShiyu", "action": "learn"}
json_data = json.dumps(body).encode("utf-8")

post_req = Request(
    url,
    data=json_data,
    headers={"Content-Type": "application/json"}
)
with urlopen(post_req) as response:
    print("urllib POST 结果:", response.read().decode("utf-8"))
```
`urllib`库比较古早了，好处是不需要安装任何sdk。但是写法比较繁琐，不知道为什么要用一个上下文管理器来做。

### 2. `requests`库
```PYTHON
import requests

url = "https://httpbin.org/anything"

# --- 1. GET 请求 ---
# 用 params 传查询参数
response = requests.get(url, params={"search": "python"})
print("requests GET 结果:", response.json())


# --- 2. POST 请求 ---
# 用 json 参数直接传字典，requests 会自动帮你转 JSON 字符串并设置请求头
body = {"name": "ZhangShiyu", "action": "learn"}
response = requests.post(url, json=body)
print("requests POST 结果:", response.json())
```

这里也是同步写法，在运行到`response = requests.get(url)`的时候就会被阻塞了。同时在解析数据，也就是`response.json()`的时候也会有微小的阻塞。

### 3.全能库`httpx` 既能写同步，也能写异步请求
写法几乎和`requests`一模一样。
同步写法：
```python
import requests

url = "https://httpbin.org/anything"

# --- 1. GET 请求 ---
# 用 params 传查询参数
response = requests.get(url, params={"search": "python"})
print("requests GET 结果:", response.json())


# --- 2. POST 请求 ---
# 用 json 参数直接传字典，requests 会自动帮你转 JSON 字符串并设置请求头
body = {"name": "ZhangShiyu", "action": "learn"}
response = requests.post(url, json=body)
print("requests POST 结果:", response.json())
```
异步写法：
```python
import httpx
import asyncio

async def main():
    url = "https://httpbin.org/anything"
    
    # 必须使用异步客户端上下文管理器
    async with httpx.AsyncClient() as client:
        
        # --- 1. 异步 GET 请求 ---
        response_get = await client.get(url, params={"search": "python"})
        print("httpx 异步 GET 结果:", response_get.json())
        
        # --- 2. 异步 POST 请求 ---
        body = {"name": "ZhangShiyu", "action": "learn"}
        response_post = await client.post(url, json=body)
        print("httpx 异步 POST 结果:", response_post.json())

# 运行异步函数
asyncio.run(main())
```

### 4.纯异步库`aiohttp`
```python
import aiohttp
import asyncio

async def main():
    url = "https://httpbin.org/anything"
    
    # 必须通过 ClientSession 建立一个异步会话
    async with aiohttp.ClientSession() as session:
        
        # --- 1. 异步 GET 请求 ---
        # 注意：params 直接传字典，aiohttp 会自动拼接
        async with session.get(url, params={"search": "python"}) as response:
            get_data = await response.json()  # 解析 JSON 也需要 await
            print("aiohttp 异步 GET 结果:", get_data)
        
        # --- 2. 异步 POST 请求 ---
        body = {"name": "ZhangShiyu", "action": "learn"}
        # 注意：传 JSON 数据用 json 参数，它会自动转码
        async with session.post(url, json=body) as response:
            post_data = await response.json()
            print("aiohttp 异步 POST 结果:", post_data)

# 运行异步函数
asyncio.run(main())
```
